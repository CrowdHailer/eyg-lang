# EYG cloud and ElizaOS

ElizaOS is an open source framework and runtime for autonomous agents with characters, plugins, many platform clients and a cloud offering.

| | EYG cloud | ElizaOS |
| --- | --- | --- |
| Focus | Teams running agents and automations in their chats | Autonomous agents with personas, plugins and on chain actions |
| Configuration | EYG programs | Character files and TypeScript plugins |
| Limiting agents | Channel shells | Plugin selection and plugin settings |
| Extending | Write effects or EYG, connect services in `connections` | Write TypeScript plugins |

## Human agency

An autonomous agent is designed to act on its own. EYG cloud is designed so that people decide what agents may do, and agents propose: triggers cannot act from their patterns, and every action passes a gate written by a person.

## Choose ElizaOS when

- You are building a public facing autonomous character or a product on its plugin ecosystem.
- You need its blockchain and social integrations.

## Choose EYG cloud when

- You want an agent that works for a team, speaks only when it chooses, and whose permissions are visible to the team.
