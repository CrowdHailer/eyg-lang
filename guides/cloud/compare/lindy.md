# EYG cloud and Lindy

Lindy is a hosted platform for building AI agents that work across email, calendars, chat and business apps.

| | EYG cloud | Lindy |
| --- | --- | --- |
| Hosting | Your own server | Lindy's cloud |
| Building agents | Configure in EYG, agents act through effects | No code builder with triggers and actions |
| Permissions | Channel shells written in EYG | Settings in the builder |
| Source | Open source | Closed source |

## Human agency

No code builders hide their rules behind forms. EYG cloud agents have no capability that is not written in their channel's shell, and the shell is a program anyone in the team can read.

## Choose Lindy when

- You want ready made assistants for email and scheduling without running infrastructure.

## Choose EYG cloud when

- You want to see and control exactly what each agent can do, in code you own.
