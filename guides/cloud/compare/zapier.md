# EYG cloud and Zapier

Zapier is a hosted automation service that connects thousands of apps with Zaps, and offers AI agents and chatbots.

| | EYG cloud | Zapier |
| --- | --- | --- |
| Hosting | Your own server | Zapier's cloud |
| Source | Open source | Closed source |
| Automations | Triggers written in EYG | Zaps built in an editor, AI steps |
| Integrations | A handful of connections and any HTTP API through `Fetch` | Thousands of app integrations |
| Permissions | Programmable policies per channel | Account and app connection permissions |

## Human agency

Hosted automation is convenient but the platform decides what is possible. With EYG cloud you can read the code that runs your automations, move it, and write rules the vendor did not think of.

## Choose Zapier when

- You need an integration with a specific business app today and do not want to run anything.

## Choose EYG cloud when

- You want to own the runtime, the data and the rules, and change any of them.
