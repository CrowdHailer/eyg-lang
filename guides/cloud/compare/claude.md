# EYG cloud and Claude

Claude is Anthropic's assistant, available in its apps, in Slack and as Claude Code, which runs coding agents locally or in the cloud and can be scheduled. EYG cloud can use any model provider, its examples use Ollama.

| | EYG cloud | Claude |
| --- | --- | --- |
| What it is | A self hosted cloud for agents in your channels | An assistant and agent products from a model provider |
| Model | Any provider overlay supports | Claude models |
| Permissions | Channel shell policies in EYG | Product permission modes, tool settings and connectors |
| Automation | Triggers on events from chats and services | Product features such as scheduled tasks |

## Human agency

Assistant products decide which controls to expose. EYG cloud makes the controls a program you write, so the people using agents decide what they may do.

## Choose Claude when

- You want the best Claude experience with no setup.
- You want an agent that edits code in a repository.

## Choose EYG cloud when

- You want your team's agents to run on your server, with your policies, on any model, including Claude.
