# EYG cloud and ChatGPT agents

ChatGPT is OpenAI's assistant. OpenAI also offers tools for building agents, such as an agent builder and an agents SDK, and integrations for Slack and other apps.

| | EYG cloud | ChatGPT agents |
| --- | --- | --- |
| What it is | A self hosted cloud for agents in your channels | An assistant and agent building tools from a model provider |
| Model | Any provider overlay supports | OpenAI models |
| Permissions | Channel shell policies in EYG | Product settings, guardrails in the builder or SDK |
| Hosting | Your own server | OpenAI's cloud, or your app with the SDK |

## Human agency

Guardrails defined in a vendor's builder belong to that vendor's product. EYG cloud's guardrails are EYG you keep with your workspace and can move to another model or server.

## Choose ChatGPT agents when

- You want OpenAI's models and tools with the least setup.

## Choose EYG cloud when

- You want one place, under your control, where every agent's permissions are written down.
