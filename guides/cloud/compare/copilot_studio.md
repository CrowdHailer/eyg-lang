# EYG cloud and Microsoft Copilot Studio

Copilot Studio is Microsoft's hosted builder for agents in Teams, Microsoft 365 and other channels, with connectors to Microsoft and third party services and administration through the Power Platform.

| | EYG cloud | Microsoft Copilot Studio |
| --- | --- | --- |
| Hosting | Your own server | Microsoft's cloud |
| Configuration | EYG programs | A low code designer and Power Platform environments |
| Governance | Policies are code, reviewed like code | Admin centre policies, data loss prevention and environments |
| Channels | Chats through the channel interface | Teams, Microsoft 365 Copilot, web and more |

## Human agency

Enterprise platforms give agency to administrators through consoles. EYG cloud gives it to anyone who can read the workspace: the same EYG that configures agents shows what they can do.

## Choose Microsoft Copilot Studio when

- Your organisation runs on Microsoft 365 and needs its governance and connectors.

## Choose EYG cloud when

- You want governance you can read, test and change yourself, without a vendor's admin centre.
